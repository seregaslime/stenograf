# Чек-лист ручного тестирования

Автоматика (гоняется командами, подробности в README → «Тесты»):

```bash
cd server
.venv/bin/python -m pytest                  # юнит-тесты (быстро)
.venv/bin/python -m pytest -m integration   # реальная ECAPA на синтезе
.venv/bin/python -m pytest -m e2e           # встречи целиком на одноразовом сервере
cd ../client && npm run typecheck && npm run build
```

Ниже — то, что автоматика проверить не может: реальный микрофон, звонки,
железо. Проходится перед показом/релизом; ✅/❌ и заметки — прямо в таблице.

| № | Сценарий | Шаги | Ожидаемо | Статус |
|---|---|---|---|---|
| 1 | Своя речь | Встреча 3–5 мин, говорить в микрофон | Реплики уходят в «Вы»; во вкладке Спикеры у «Вы» появились «звучания» голоса (▶ у отпечатков); вторая встреча узнаёт сразу | ☐ |
| 2 | Звонок в наушниках | Telegram/Zoom, системный звук «Автоматически», наушники | Собеседник — новый спикер; после переименования узнаётся по имени на следующей встрече | ☐ |
| 3 | Звонок на колонках | То же, но без наушников | Реплики собеседника НЕ дублируются и НЕ пишутся в «Вы» (текст может быть чуть хуже — «комнатный» тембр) | ☐ |
| 4 | Двое у одного мака | Два человека по очереди говорят в микрофон | Два профиля: «Вы» и новый спикер; реплики не путаются | ☐ |
| 5 | Длинная встреча | 40–60 мин (подкаст в системный звук), следить за Activity Monitor | Реплики не отстают; память не растёт бесконтрольно; резюме построилось (длинное — по сокращённому транскрипту) | ☐ |
| 6 | Переключение движков | Настройки: gigaam rnnt → ctc → whisper small → mlx small, между ними короткие записи | Статус честный («загружается…» → «загружена»), реплики приходят на каждом движке; на rnnt задержка комфортная | ☐ |
| 7 | Ollama выключена | Погасить `ollama serve`, провести встречу | Транскрипция работает; у встречи понятная ошибка резюме; после запуска Ollama кнопка повторной генерации срабатывает | ☐ |
| 8 | Рестарт сервера | Убить сервер посреди встречи | Клиент показывает ошибку и не виснет; после рестарта встреча в истории со статусом «done» | ☐ |
| 9 | Упакованное приложение | `npm run dist:mac`, установить .dmg | Свои разрешения (микрофон + запись экрана) запрашиваются; автозахват системного звука работает; полный сценарий встречи проходит | ☐ |
| 10 | Подсказки ИИ | Включить подсказки, встреча 5+ мин | Подсказки приходят примерно раз в 25 с; транскрипция не тормозит | ☐ |

Примечания:
- Сценарии 1–3, 6, 7 — обязательные перед показом; 9 — если демо на собранном
  приложении, а не в dev-режиме.
- Порог диаризации под свои голоса проверяется скриптом:
  `.venv/bin/python scripts/eval_voices.py --samples` (после сценариев 1–2
  в базе уже будут звучания с аудио).
